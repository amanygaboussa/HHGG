# مشروع إدارة مكتبة رقمية (Library Management System)

نظام بسيط لإدارة مكتبة رقمية باستخدام لغة Java، يتيح للمستخدم إدارة الكتب والمستعيرين وعمليات الإعارة.

## المعلومات الشخصية

- الاسم واللقب:[اماني قابوسه]
- الفوج: [1]
- تاريخ التسليم: 1 ماي 2025

## وصف المشروع

يتضمن هذا المشروع تطبيقًا نصيًا (Console Application) يهدف إلى:

- إضافة كتب جديدة (ورقية أو إلكترونية).
- إضافة مستعيرين جدد.
- إعارة واسترجاع الكتب.
- عرض حالة الكتب (معار / متوفر).
- عرض الكتب التي استعيرت من طرف مستعير معين.

## مفاهيم البرمجة الكائنية (OOP) المطبقة

- التغليف (Encapsulation): حماية خصائص الكائنات عبر private وgetters/setters.
- الوراثة (Inheritance): إمكانية إنشاء أنواع مختلفة من الكتب.
- تعدد الأشكال (Polymorphism): استخدام نفس الدوال بطرق مختلفة حسب نوع الكائن.
- الواجهات (Interfaces): يمكن استخدامها لاحقًا لتوحيد التعامل مع أنواع الكتب.
